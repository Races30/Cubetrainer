# CubeTrainer
![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=for-the-badge&logo=Flutter&logoColor=white) ![Dart](https://img.shields.io/badge/dart-%230175C2.svg?style=for-the-badge&logo=dart&logoColor=white)

CubeTrainer è un'applicazione avanzata sviluppata in Flutter dedicata agli appassionati del Cubo di Rubik (speedcuber). L'app offre un ecosistema completo per allenarsi, monitorare i propri tempi, analizzare le statistiche e migliorare le proprie performance attraverso funzionalità mirate come l'allenamento specifico sugli algoritmi (OLL/PLL) e un Coach Virtuale potenziato dall'intelligenza artificiale.

## 🎓 Progetto Capolavoro UNICA

Questa applicazione è stata sviluppata e presentata ufficialmente come **"Capolavoro"** per **UNICA**, la piattaforma ministeriale scolastica italiana. Il progetto dimostra l'acquisizione di competenze tecniche avanzate nello sviluppo di applicazioni mobili multipiattaforma, architettura del software, gestione dello stato locale ed integrazione di intelligenza artificiale, incarnando al meglio l'obiettivo di eccellenza e innovazione richiesto dal portfolio dello studente.

## ✨ Funzionalità Principali

*   ⏱️ **Timer e Generatore di Scramble**: Cronometro di precisione per misurare i tempi di risoluzione, accompagnato da un generatore di sequenze di mescolamento (scramble) per garantire allenamenti standardizzati.
*   📊 **Statistiche Avanzate e Grafici**: Tracciamento completo dei progressi (tra cui Ao5, Ao12 e Best Time) con visualizzazione tramite grafici interattivi per analizzare la propria evoluzione nel tempo.
*   🧠 **Allenamento Specifico OLL / PLL**: Modalità dedicate per esercitarsi in modo isolato sull'Orientation of Last Layer (OLL) e Permutation of Last Layer (PLL), algoritmi fondamentali per il metodo avanzato CFOP.
*   🤖 **Coach Virtuale AI**: Un assistente intelligente integrato (basato su Google Generative AI / Gemini) che analizza le sessioni e fornisce consigli mirati per migliorare la propria tecnica.
*   🎯 **Sessioni di Training e Reportistica**: Creazione e gestione di sessioni di allenamento con obiettivi specifici e report di fine sessione dettagliati per valutare i propri traguardi.
*   🏆 **Leaderboard**: Classifiche integrate per analizzare i propri tempi migliori, incentivare il miglioramento continuo e sfidare se stessi.
*   🔗 **Condivisione tramite QR Code**: Funzionalità di generazione e scansione di QR Code per condividere rapidamente scramble o risultati delle sessioni con altri cuber.

## ⚙️ Installazione

Per scaricare ed eseguire il progetto in locale sul tuo computer, segui questi semplici passaggi:

1. Clona questo repository:
```bash
git clone https://github.com/races30/Cubetrainer.git
```

2. Spostati nella cartella del progetto appena clonata:
```bash
cd Cubetrainer
```

3. Scarica tutte le dipendenze necessarie:
```bash
flutter pub get
```

4. Esegui l'applicazione sul tuo dispositivo o emulatore preferito:
```bash
flutter run
```
